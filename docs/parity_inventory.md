# Official TUI workflow inventory (F10-A)

**Scope and provenance.** This is a source-derived inventory of user workflows represented by the official OpenCode TUI at V2.0.20, commit [`84c9be93a56304a108f1a22df0c5d62c26d5b6ca`](https://github.com/anomalyco/opencode/tree/84c9be93a56304a108f1a22df0c5d62c26d5b6ca). On 2026-10-01, narrow R01/R02 Joycode/TUI coexistence was observed in a disposable pinned v2.0.20 sandbox: read-only `/api/info`, connection-owned SSE, and `server.connected` only. No provider call, prompt, session mutation, or user-service change occurred. This is transport/model-level evidence, not broad workflow parity; remaining rows retain their source-only/mock-only/planned/blocked classifications.

Status vocabulary: **source-only** means indicated by inspected source, not empirically verified; **planned** means mapped to a Joycode slice; **mock-only** means only synthetic/local evidence exists; **live verified** requires approved runtime evidence; **blocked** means an evidence, contract, or approval gate prevents closure; **experimental** means optional/unstable source behavior. Proposed, external, and plugin workflows remain pending decision, not exclusions.
